# a chapter's name ("Mangakakalot Ch. 53.cbz"). An arrival whose name starts
# with one of these, followed by a chapter or episode token, is named after
# its series folder instead (scripts/cbz_core.py, _without_group_prefix).
#
# One group per line, written as it appears. Matching ignores case, spaces,
# hyphens, underscores and punctuation ("LOST VEYL" also matches
# "LOST_VEYL"), and must be exact: "Alpha" never matches "Alpha Scans".
# Blank lines and lines starting with # are ignored.
#
# To add a group: add one line, keep the list sorted, and add a test case if
# it is unusual. Do not add a name that is also a series title (a library
# folder). A listed name may hold a digit ("Manhwa18"): an exact match here
# overrides the digit rule (David, 2026-11-10). It never overrides the
# structural checks: a line that is or holds a part, season, volume, episode
# or chapter marker, or a structural or special word ("Part 2", "S2", "Side",
# "Extra", "One-shot", ...), is never taken for a group, so it has no effect.
